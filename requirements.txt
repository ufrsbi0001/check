# ── python-binance version note ─────────────────────────────────────
# core/client.py uses the futures algo-order methods
# (futures_get_open_algo_orders / futures_cancel_algo_order) inside
# _get_open_algo_orders / _cancel_algo_order. If the installed release
# does not expose them, those helpers silently return [] and the bot
# cannot cancel SL/TP orders attached to positions — which is unsafe
# in production. Minimum known-good release: 1.0.19.
# assert_sdk_methods() in core/client.py checks this at startup and
# raises if the methods are missing, so a too-old install will fail
# loudly at boot. The floor below is defensive; any 1.0.x you already
# use that passes assert_sdk_methods() is fine.
# ─────────────────────────────────────────────────────────────────────
